Redirect

Send the shopper to widget.url as a full page, like PayPal. On completion the widget navigates the page to returnUrl?widgetUuid={uuid}. Do not iframe it.

← integration guide

Create

POST https://api.sandbox.myticketpro.app/octo/widgets
Authorization: Bearer <token>

{"productId": "...", "optionId": "widget", "availabilityId": "...", "returnUrl": ""}

Redirect

window.location.assign(widget.url);
