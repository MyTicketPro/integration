MyTicketPro widget example

A small shop that sells tickets through the MyTicketPro widget. Each page is one step:

Page What the shopper does Browser file Server file
/products/ Picks an event (product) and a date (availability) client/products/products.js server/routes/products.js
/widget/ Picks tickets (unit items) in the widget, then enters contact details and confirms client/widget/widget.js server/routes/widgets.js, server/routes/confirm.js
/booking/ Sees the confirmed booking client/booking/booking.js server/routes/bookings.js
