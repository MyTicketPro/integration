What happened

  1. widget.js asked our server for a widget. POST /api/widgets
  2. server/routes/widgets.js created it at MyTicketPro. POST /octo/widgets
  3. widget.js put widget.url in the iframe and listens to its messages.
  4. Every message the widget sends shows up in Widget events below.
  1. The widget sent octo.widget.complete.
  2. widget.js replaced the widget with this checkout.
  3. MyTicketPro holds the tickets for 15 minutes, because the widget was created with createBooking: true.
  4. A real shop takes payment here.
  5. "Pay and confirm" sends the widgetUuid and the contact to our server. POST /api/confirm
  6. server/routes/confirm.js reads the widget, then confirms the booking. GET /octo/widgets/{uuid}
    POST /octo/bookings/{uuid}/confirm
